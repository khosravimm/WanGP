# رابط اصلی WanGP 19 در محیط CPU — وضعیت آزمایشی

## خواسته و دامنه

این مسیر به‌جای ساختن یک وب‌اپ تقلیدی، فایل اصلی `wgp.py` و رابط Gradio رسمی WanGP v19.0 را اجرا می‌کند. حالت قبلی `wgp.py --cpu-only` همچنان رابط سبک صوتی جداگانه را روی پورت 18084 راه‌اندازی می‌کند؛ **حالت رابط اصلی**، اجرای `wgp.py --offline --server-port 18087` است.

این یک نمونه آزمایشی برای **بالا آمدن UI اصلی** است. بارگذاری مدل‌های تولید تصویر/ویدئو، MMGP offload، Deepy و تمام توابع برنامه بدون CUDA نه تضمین شده و نه آزموده‌شده است. مدل‌های GPU باید پشت capability gate از کار بیفتند یا به backend مجاز تبدیل شوند؛ پنهان کردن خطا یا شبیه‌سازی خروجی مجاز نیست.

## اصلاحات حداقلی نسبت به upstream

1. در `shared/attention.py` برای نبود CUDA، capability مقدار `(0,0)` می‌گیرد؛ **به‌معنای GPU جعلی نیست** و تنها جلوی crash در واردکردن ماژول را می‌گیرد.
2. در `models/wan/modules/t5.py` مقدار پیش‌فرض device هنگام import دیگر به `torch.cuda.current_device()` وابسته نیست.
3. در `wgp.py` تشخیص معماری GPU در محیط بدون CUDA امن شده و `processing_device` پیش‌فرض `cpu` است.
4. افزونه Gradio `plugins/moss_tts_cpu` به‌عنوان افزونه فعال در `wgp_config.json` این نصب اضافه شد؛ خود فایل پیکربندی محلی و محرمانه است و وارد Git نمی‌شود.

## وضعیت آزمون واقعی Sal-AI (E2 — UI startup only)

- سخت‌افزار: 192 GiB RAM؛ PyTorch CUDA build نصب است اما `torch.cuda.is_available()==False`.
- اجرا با Python موجود در `/opt/Progs/Wan2GP/env_uv/bin/python` از Worktree مجزای `/opt/Progs/WanGP-CPU-v19`.
- HTTP GET `http://127.0.0.1:18087/` → 200؛ محتوای HTML خود WanGP.
- HTTP GET `http://127.0.0.1:18087/config` → 200؛ 3147 مؤلفه Gradio، عنوان `WanGP` و حضور `moss_tts_cpu` در Config.
- سرویس کاربر `wangp-original-ui-cpu.service` enabled/active؛ فقط روی `127.0.0.1:18087`.
- سرویس‌های `wangp-cpu.service` (18084)، `moss-tts-nano-cpu.service` (18083) و `wangp-cpu-whisper-asr.service` (18085) جداگانه برقرارند.
- آزمایش مرورگر گرافیکی شامل کلیک روی تمام دکمه‌ها و تولید خروجی از داخل UI اصلی **هنوز انجام نشده است**.

## امنیت / نگهداری

- سرویس UI اصلی را روی LAN یا اینترنت بدون احراز هویت منتشر نکنید؛ listen پیش‌فرض loopback است.
- برای اتصال از راه دور SSH tunnel یا reverse proxy دارای احراز هویت و TLS نیاز است.
- روی Sal-AI بسته‌های PyTorch/Gradio/MMGP موجود در `env_uv` استفاده شده‌اند؛ **این وابستگی‌ها هنوز مستقل از برنامه اولیه Wan2GP نیستند**.
- هنگام نخستین راه‌اندازی، WanGP ممکن است به دانلود بسته جانبی ffmpeg اقدام کند. گزینه `--offline` همه مسیرهای دانلود غیرمدل را در کد upstream غیرفعال نمی‌کند. این رفتار باید در نسخه سخت‌گیری‌شده کنترل شود.
- فایل‌های ساخته‌شده خودکار `ffmpeg_bins/` و `startup.lock` در این نسخه به Git اضافه نشده‌اند.

## Rollback

```bash
systemctl --user disable --now wangp-original-ui-cpu.service
```

این عملیات UI اصلی آزمایشی را متوقف می‌کند و بر وان‌جی‌پی اصلی و سرویس‌های صوتی مستقل اثری ندارد.

## معیار تکمیل مرحله بعد

- بررسی کل رابط در مرورگر واقعی و تأیید نمایش صحیح تب‌ها و فرم‌ها.
- مسیرهای ساخت خروجی صوت از همان تب اصلی/افزونه، نه فقط API مستقل.
- حذف/غیرفعال‌سازی کنترل‌شده مدل‌هایی که نیازمند GPU هستند با پیام شفاف.
- جداسازی کامل virtualenv از نصب قدیمی و pin کردن dependencyها.
- آزمون پس از reboot و انتشار نسخه جدید به صورت PR در فورک.
